# Игры разума (JS)

[![hexlet-check](https://github.com/OttIvan/frontend-project-44/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/OttIvan/frontend-project-44/actions)

Учебный проект на JavaScript: набор консольных игр, в которых нужно отвечать на вопросы, решать арифметические выражения и применять логическое мышление.

## Стек

- JavaScript
- Node.js
- npm
- ESLint-совместимый линтер Oxlint и форматтер Oxfmt

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/OttIvan/frontend-project-44.git
cd frontend-project-44
npm ci
npm link
```

## Использование

Запускайте игры командами:

```bash
brain-games
brain-even
brain-calc
brain-gcd
brain-progression
brain-prime
```
